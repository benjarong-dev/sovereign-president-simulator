# Sovereign Skylines V4 — 3D Megacity, Multi-Lane Highways, BTS Skytrain & Fiscal Simulator

Interactive **3D Diorama WebGL (Three.js + PCFSoftShadowMap) & 2D Isometric Fallback** city-building simulation engineered with modular **ES Modules**, zero npm runtime dependencies, and **15 automated tests**.

- **Live Browser Sandbox (GitHub Pages):** https://benjarong-dev.github.io/sovereign-president-simulator/

## Core V4 Capabilities
- **2 / 4 / 6 / 10-Lane Roads & 3D Pedestrians:** Auto-bridges, 3-phase traffic signals, and sidewalk pedestrians.
- **Rail Family (Tram, Heavy Rail & Elevated BTS Skytrain):** Custom tracks, stations, and articulated multi-car trains.
- **Hydroelectric Dam, Football Stadium & Mega Mall:** 480 MW river dam, floodlit stadium, sports complex, and mall.
- **Dynamic Lighting & 4 Info Views:** Day/Dusk mode, power deficit window flicker, and Fiscal/Approval/Infra/Pollution heatmaps.
